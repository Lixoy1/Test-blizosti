# Между нами

Одноразовый двухсторонний проект для совместного самоисследования: близость, доверие, взаимность, характер, романтическое влечение и готовность строить реальные отношения.

## Состав анкеты

- 60 авторских вопросов о вашей связи и совместном будущем.
- 50 пунктов IPIP Big-Five Factor Markers — пять личностных черт.
- 15 пунктов TLS-15 — близость, страсть и обязательство.
- Всего 125 обязательных вопросов в 8 блоках.
- Два отдельных приглашения, два личных профиля и один сравнительный отчёт.
- Без сводного процента совместимости: выводы представлены по измерениям.

### Методические ограничения

IPIP — открытый банк пунктов. Пункты Big Five переведены на русский для этого проекта как рабочая версия; это не валидированная русская адаптация и не основание для сравнения с популяционными нормами. TLS-15 — переводная рабочая версия треугольной модели любви. Анкета предназначена для личной рефлексии, а не для клинической диагностики или достоверного предсказания будущего пары.

## Хранение и версии

- После отдельного согласия каждый ответ автоматически сохраняется в PostgreSQL.
- На сервере хранится текущий черновик и журнал изменений с датой, временем, старым и новым значением каждого изменённого ответа.
- Незавершённое прохождение можно продолжить по той же личной ссылке с другого устройства.
- Завершённая версия неизменяема. Новое прохождение создаёт новую версию; предыдущие версии и журнал не перезаписываются.
- Каждый участник видит свой журнал изменений. После завершения обеих анкет оба видят общий сравнительный отчёт и сохранённые ответы друг друга.
- У каждого участника есть действие удаления собственных черновиков, завершённых версий и истории. Удаление аннулирует именно его ссылку.
- Токены ссылок хранятся в базе в виде SHA-256-хеша. Не публикуйте персональные ссылки.

## Бесплатное развёртывание

Рекомендуемая связка: Render Free для Node.js Web Service + Neon Free для PostgreSQL. Не используйте бесплатную PostgreSQL Render для сохранения этой анкеты: её бесплатные базы имеют срок действия 30 дней.

### 1. Создать базу Neon

1. Создай бесплатный проект на https://neon.com.
2. Создай базу PostgreSQL.
3. Скопируй строку подключения (для Node.js/pg; можно pooled connection string).
4. Не публикуй её и не добавляй в GitHub.

У бесплатного Neon есть лимиты по вычислениям, хранилищу и сетевому трафику. Данные остаются в хранилище при масштабировании вычислений до нуля, но бесплатный тариф не является гарантией бессрочного хранения или резервного копирования. Для этого одноразового проекта после завершения обеими сторонами скачайте JSON-экспорт и сохраните его отдельно.

### 2. Создать Web Service на Render

- New → Web Service.
- Репозиторий: `Lixoy1/Test-blizosti`.
- Ветка: `main`.
- Runtime: Node.
- Build Command: `npm install`.
- Start Command: `npm start`.
- Instance Type: Free.
- Health Check Path: `/api/health`.

В Environment добавь:
- `NODE_ENV=production`
- `DATABASE_URL` — строка подключения Neon.

Веб-сервис может засыпать после периода без активности. Это не стирает PostgreSQL: база находится отдельно.

## Локальный запуск

Нужен Node.js 20+ и PostgreSQL.

```bash
npm install
cp .env.example .env
```

Заполни `DATABASE_URL`, затем:

```bash
npm run check
npm start
```

Открой http://localhost:3000. SQL-схема и миграции применяются сервером при запуске.
