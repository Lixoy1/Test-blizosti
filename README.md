# Между нами

Закрытое двухстороннее исследование близости, доверия, взаимности и готовности перейти от общения к реальным отношениям.

## Что реализовано

- 60 обязательных вопросов в 6 тематических блоках.
- Два отдельных доступа: участник A — Василий, участник B — Полина.
- Локальный черновик в браузере до финальной отправки.
- Явное согласие перед прохождением: ответы сохраняются и после завершения обеих анкет становятся доступны обоим участникам.
- Личный отчёт после завершения своей анкеты.
- Общий сравнительный отчёт только после завершения обеих анкет.
- Сравнение шести измерений, различий по вопросам и текстовых ответов.
- Экспорт JSON и печать отчёта в PDF.
- PostgreSQL для постоянного хранения. В репозитории нет ответов, ключей доступа или персональных данных участников.
- Адаптивный интерфейс для телефона и компьютера, анимации с поддержкой prefers-reduced-motion.

## Локальный запуск

Нужен Node.js 20+ и PostgreSQL.

```bash
npm install
cp .env.example .env
```

Укажи строку подключения PostgreSQL в DATABASE_URL, затем:

```bash
npm start
```

Открой http://localhost:3000.

Схема таблиц создаётся сервером при запуске из sql/schema.sql. Если DATABASE_URL не задан, главная страница откроется, но создание пространства и сохранение ответов будут отключены — приложение не подменяет постоянную базу временным хранилищем.

## Развёртывание на Render

1. Создай PostgreSQL database в Render.
2. Создай Web Service из репозитория Lixoy1/Test-blizosti, ветка main.
3. Build command: npm install. Start command: npm start.
4. В Environment добавь NODE_ENV=production и DATABASE_URL, взяв Internal Database URL созданной базы, если сервис и база находятся в одном Render workspace/region.
5. Health check path: /api/health.
6. После первого успешного запуска сервер создаст таблицы автоматически.

В репозитории есть render.yaml как стартовая конфигурация веб-сервиса. Переменную DATABASE_URL нужно задать в панели Render; секреты не коммитить в GitHub.

## Доступ и приватность

- Каждая ссылка содержит случайный длинный токен. Он хранится в базе только в виде SHA-256-хеша.
- Ссылка является ключом доступа: не публикуй её и не пересылай посторонним.
- До завершения обеих анкет API не отдаёт участнику ответы партнёра.
- После завершения обеих анкет личные и сравнительные отчёты доступны по каждой из двух ссылок, потому что оба заранее подтверждают это отдельным согласием.
- После отправки анкета становится неизменяемой.
- Не вводите в свободные ответы адреса, телефоны, пароли, банковские данные и другую информацию, которая не нужна для разговора об отношениях.
- Это авторский опросник для рефлексии, не медицинская или клиническая диагностика. Баллы показывают только самооценку участника.

## Проверка

```bash
npm run check
```

Проверка подтверждает количество вопросов, уникальность ID, принадлежность к блокам, типы ответов и наличие показателей в каждом измерении.

## Структура

```text
public/
  index.html          каркас интерфейса
  styles.css          оформление и адаптивность
  app.js              клиентская логика и отчёты
  questions.json      единый источник вопросов и шкал
  assets/             образы участников и favicon
server.js             API, приватные токены, сохранение и сравнение
sql/schema.sql        PostgreSQL schema
scripts/              проверки структуры анкеты
render.yaml           базовая конфигурация Render
```
